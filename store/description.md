Housing Editor browses compatible HouseDecor rows through wxl-db2, places
installed M2 decor locally, and supports selection, move, rotate, scale,
free-build camera, and experimental client-local terrain tools.

Install wxl-db2 first. The Hub release contains no WoW data, retail UI art,
DB2/TSV sidecars, thumbnails, test-client content, or custom object files. It
uses compatible data already present on the user's client and falls back to
safe placeholders when optional local art or names are unavailable.

Press Insert or use the draggable building launcher to open the editor.
